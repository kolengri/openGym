# SVG mannequin motion style prototype

Status: rejected visual exploration, superseded by `../human-animation-base/`.
The user requested professionally authored human anatomy instead of these custom
procedural body contours. Retained only as exploration history.

Original vector artwork explores a neutral mannequin between flat exercise
illustrations and an anatomical model. The supplied reference screenshots
informed the broad visual direction; their figures and geometry were not traced.
No licensed Gym Visual media was used as input. No paid generation was submitted.

`viewer.html` is a self-contained offline page with three motion choices, a
timeline and muscle highlight toggle. The mannequin has no garments or genital
anatomy. Arms use a lighter fill and stronger outlines so they remain separate
from the torso. Continuous limb contours connect across elbows and knees.
Separate muscle shapes, tendons, creases and fiber lines provide anatomical detail. It uses SVG paths and a
small JavaScript renderer. `5965-mannequin.svg`, `SquatPreview.svg` and
`ArmRaisePreview.svg` use baked SMIL path animation and need no JavaScript or 3D
runtime. The first exercise is a 5.2-second lateral-step loop. The other two clips
are deformation/style demonstrations. `5965-svg.mp4` is an optional raster export
of the standalone first SVG.

The shape drawing is newly authored vector geometry. Only skeletal movement
samples are reused from our independently authored Blender clips. SVG consumers
do not load the generated body mesh, textures, Three.js or Blender. The squat uses a strict sagittal view; lateral steps and arm raises use a frontal
view. The camera looks perpendicular to each demonstrated movement plane.
Fixed-view artwork can be authored directly in 2D; arbitrary camera rotation and
complex limb/equipment occlusion require separate illustration decisions.

Muscle overlays are illustrative regions: red for the selected primary zones,
amber for abdominal stabilizers. They are not anatomical segmentation, measured
activation or approved exercise instruction. Muscle forms follow their joint segments and show illustrative changes in belly
width/opacity during knee flexion. These are authored visual cues, not a
biomechanical muscle simulation. Precise anatomical segmentation, hand grips and
finished equipment interaction still require exercise-specific review.

## Reproduction

```sh
blender -b -t 2 -P artifacts/athlete-svg-v1/sample_poses.py
python3 artifacts/athlete-svg-v1/build_viewer.py
node artifacts/athlete-svg-v1/export_and_review.mjs
EXERCISE_RENDERER="SVG / Chromium" swift artifacts/first-exercise-3d/encode.swift artifacts/athlete-svg-v1/frames artifacts/athlete-svg-v1/5965-svg.mp4 30 800000
```

The Blender source is `../athlete-clean-v2/athlete-motion.blend` (generated by its
`animate_previews.py`); `poses.json` is retained so using/rebuilding the SVG viewer
does not require Blender. Export/review uses the already installed Playwright
dependency and Chromium executable from the earlier media pilot. Set
`EXERCISE_CHROME` to override its path. The MP4 encoder uses macOS AVFoundation.

`review.json` records successful standalone SMIL rendering, clip exports, muscle
control behavior and page errors. Review PNGs show each clip's middle pose.
This is an artifact-only trial; the application and its media catalog are unchanged.
