# Batch 006 — ten motions and the repaired foot grasp

This review adds ten equipment-free catalogue records and replaces the user-rejected hand/foot grasp in 1512. Delivery is live GLB + Three.js animation. The canvas is transparent, inactive skin is neutral, and only the declared training regions receive soft warm load or cyan stretching emphasis. The fields represent catalogue muscle labels, not measured temperature, force or recruitment.

Dynamic demonstrations show both sides in five seconds. The stretch has a two-second entry, one-second demonstration hold and two-second return; its catalogue workout hold of 20–30 seconds is stated separately. Joint angles, motion tempo, contact staging and the precise upward-reach mechanism of 5106 are declared authoring choices, not source measurements. Cardiovascular system remains the original target for hops and punches; visible muscle fields use explicitly declared proxies from the source secondary labels.

## Playback and reuse

Open `viewer.html` directly after running `node artifacts/exercise-batches/batch-006/build.mjs` from the repository root. The generated offline file is excluded from Git. An immutable `source-revision.json` also enables `inline.html`, which fetches models from that exact source commit.

Recommended views open by default. Drag or touch rotates the body; pinch or the wheel changes scale, and reset restores the view. The grasp has a useful companion view. There are no body shadows, ambient occlusion, color textures or background plane covering the muscle fields. Shared physical assets retain separate action and muscle identities; the softened abdominal atlas is stored once for the batch.

The review uses the existing Three.js 0.186.1 runtime and its dual-quaternion adapter where declared in each clip. Generic GLB viewers without that adapter can display different deformation. No generated video, runtime vertex cache or restricted GymVisual derivative is used. `curated-delivery.json` identifies deliverable files; per-asset manifests identify source recipes and family dependencies.
