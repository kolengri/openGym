# Batch008 live exercise review

Ten equipment-free catalogue records continue the accepted catalogue order: 6121, 5172, 1987, 6014, 1986, 6539, 3214, 3204, 4935 and 3483. The review uses live GLB + Three.js, a transparent canvas, a plain inactive mannequin, soft muscle fields, two recommended views, and orbit/pinch/reset controls.

The ten catalogue actions use seven unique GLB payloads. 4935/3483 share one physical prone lift and arm sweep, with separate action identities and source muscle roles. 6539 reuses the previously accepted 4365 motion and binding, with its own source duration and latissimus emphasis. Other shared payloads retain separate motions. No video, runtime frame sequence, paid generation or restricted visual derivative is used.

`contexts/` and the pinned `intake-contract.json` preserve source instructions, equipment, limb positions, muscle labels and known failure checks. The intake contract comes from committed c7d44162 rather than unrelated policy edits in the working tree. Stretching examples compress a source hold into a five-second review cycle; the presentation retains the original workout duration separately.

Build the muscle atlas with `node artifacts/exercise-batches/batch-008/prepare-muscle-atlas.mjs`, then run `build.mjs` in the same directory. Fit camera widths with `node artifacts/exercise-batches/fit-cameras.mjs 008`, rebuild, and run the batch's `verify.mjs` and `capture-peaks.mjs`. `curate.mjs --source-only` selects accepted author sources and explicit reproduction dependencies. `curate.mjs` also selects the final review evidence. Pinned inline model verification follows publication of the accepted source commit.

`viewer.html` is the self-contained offline review. `inline.html` loads immutable model bytes for the embedded review. Native/decoded 151-sample mechanics, game QA, browser behavior and selected GPU appearance are separate evidence. Physical-device testing, production app integration and clinical muscle-recruitment validation remain outside this review.
